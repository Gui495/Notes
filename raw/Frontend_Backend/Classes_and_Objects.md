## 1. 面向对象开发
- 结构化开发：面向功能划分软件结构，自顶而下，最小子系统是方法，制约可维护性和可扩展性。
- 面向对象程序设计 OOP：
  - 软件系统看成各种对象的集合。
  - 系统结构较稳定，子系统相对独立。
  - 可重用性、可维护性、可扩展性强。

## 2. 对象
- 对象：用来描述客观事物的一个实体，由一组属性和方法构成。
- 属性：对象具有的各种特征，每个对象的每个属性有特定值。
- 方法：对象执行的操作。
- 示例：
  - 顾客张浩：姓名、年龄、体重；操作购买商品。
  - 收银员李明：员工号、姓名、部门；操作收款、打印账单、刷卡。
  - 法拉利：品牌、型号、颜色、价格；方法发动、停止、加速。
  - 小狗：颜色；方法叫、跑、吃。

## 3. 类与对象关系
- 类：具有相同属性和方法的一组对象的集合。
- 类是对象的抽象，对象是类的具体。
- 类是模板，对象是看得到、摸得着的具体实体。
- 示例：“人”类有年龄、体重、衣食住行；对象小布什、普京、克林顿。

## 4. 定义类
Java 程序以类 `class` 为组织单元，关键字 `class` 定义自定义数据类型。
```java
public class 类名 {
    // 成员变量/属性
    属性1的类型 属性1;
    属性n的类型 属性n;

    // 成员方法
    方法1;
    方法m;
}
```
- 类名首字母大写。
- 定义类步骤：定义类名、编写属性、编写方法。

## 5. 类图
- 用于分析和设计类，直观容易理解。
- 包含：类名、属性名、类型、方法名、参数、返回值类型。
- `+` public，`-` private。

## 6. 创建和使用对象
```java
类名 对象名 = new 类名();
School center = new School();
center.name = "课工场";
center.showCenter();
```
- 引用属性：`对象名.属性`
- 引用方法：`对象名.方法名()`

## 7. 方法
- 方法是一个“黑匣子”，完成特定功能并返回结果。
- 定义格式：
```java
public 返回值类型 方法名() {
    // 方法主体
}
```
- 命名：驼峰命名规则，有意义。
- 返回值：
  - 有返回值必须使用 `return` 返回该值，返回值类型为该值类型。
  - 返回值只能有一个。
  - 无返回值类型为 `void`。
- 方法调用：
  - 同类方法直接调用。
  - 其他类方法先创建对象，再用 `.` 调用。
- 示例：景区门票，根据年龄决定票价。

## 8. 小结
- 类和对象关系：类是抽象模板，对象是具体实体。
- 定义类、创建对象。
- 定义和调用方法。
- 方法返回值与 void。
