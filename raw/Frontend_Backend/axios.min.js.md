## 1. 文件说明
- 文件为 Axios v0.25.0/v0.24.0 的压缩版源码 `axios.min.js`。
- Axios 是一个基于 Promise 的 HTTP 客户端，可用于浏览器和 Node.js。
- 压缩文件不建议逐行阅读，应通过官方 API 使用。

## 2. 基本使用
### 2.1 引入
```html
<script src="axios.min.js"></script>
```
或 npm：
```bash
npm install axios
```

### 2.2 GET 请求
```javascript
axios.get('/user?ID=12345')
  .then(function (response) {
    console.log(response);
  })
  .catch(function (error) {
    console.log(error);
  });
```

### 2.3 POST 请求
```javascript
axios.post('/user', {
    firstName: 'Fred',
    lastName: 'Flintstone'
  })
  .then(function (response) {
    console.log(response);
  })
  .catch(function (error) {
    console.log(error);
  });
```

## 3. Axios API
- `axios(config)`
- `axios(url[, config])`
- 别名方法：
  - `axios.request(config)`
  - `axios.get(url[, config])`
  - `axios.delete(url[, config])`
  - `axios.head(url[, config])`
  - `axios.options(url[, config])`
  - `axios.post(url[, data[, config]])`
  - `axios.put(url[, data[, config]])`
  - `axios.patch(url[, data[, config]])`

## 4. 请求配置常用项
- `url`：请求地址。
- `method`：请求方法，默认 get。
- `baseURL`：基础 URL。
- `transformRequest`：请求数据转换。
- `transformResponse`：响应数据转换。
- `headers`：请求头。
- `params`：URL 参数。
- `data`：请求体数据。
- `timeout`：超时时间，默认 0 无超时。
- `withCredentials`：跨域请求是否携带凭证。
- `responseType`：响应类型，如 json、text、blob。
- `validateStatus`：定义 HTTP 状态码是否 resolve/reject。
- `cancelToken`：取消请求。

## 5. 响应结构
```javascript
{
  data: {},        // 服务器返回数据
  status: 200,     // HTTP 状态码
  statusText: 'OK',
  headers: {},
  config: {},
  request: {}
}
```

## 6. 拦截器
```javascript
// 添加请求拦截器
axios.interceptors.request.use(function (config) {
    // 发送请求前做些什么
    return config;
  }, function (error) {
    return Promise.reject(error);
  });

// 添加响应拦截器
axios.interceptors.response.use(function (response) {
    // 对响应数据做点什么
    return response;
  }, function (error) {
    return Promise.reject(error);
  });
```

## 7. 取消请求
```javascript
const CancelToken = axios.CancelToken;
const source = CancelToken.source();

axios.get('/user/12345', {
  cancelToken: source.token
}).catch(function (thrown) {
  if (axios.isCancel(thrown)) {
    console.log('Request canceled', thrown.message);
  }
});

source.cancel('Operation canceled by the user.');
```

## 8. 错误处理
- `axios.isCancel(thrown)` 判断是否取消。
- `error.response` 存在时表示服务器返回了状态码不在 2xx 范围。
- `error.request` 存在时表示请求已发出但未收到响应。
- `error.message` 其他错误信息。

## 9. 小结
- Axios 是基于 Promise 的 HTTP 客户端。
- 支持 GET/POST/PUT/DELETE 等别名方法。
- 支持请求/响应拦截器、取消请求、超时、自定义 headers、params、data。
- `axios.min.js` 是压缩源码，实际开发通过 API 调用。
