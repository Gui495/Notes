## 1. 反射定义
- 反射是指在程序运行期间，能够观察和修改类或者类的对象的属性和行为的特性。
- 常见使用场景：
  - 使用 JDBC 连接数据库。
  - Servlet 在 Web 容器中的加载和运行。

## 2. 反射作用
Java 反射机制提供：
- 运行时获取类的修饰符、包名、类名、实现的接口、继承的父类。
- 运行时获取类的所有属性名、修饰符、属性类型。
- 运行时获取所有方法、方法返回值类型、方法名、方法参数数量、方法参数类型。
- 运行时调用加载类的方法。

## 3. 常用 API
- `java.lang.Class`
- `java.lang.reflect.Method`
- `java.lang.Constructor`
- `java.lang.Field`
- `java.lang.Modifier`

## 4. 反射实战
- 使用 Java 反射获取类的信息。
- 获取类的构造函数参数列表，并通过构造函数实例化类。
- 获取类的所有方法信息，并调用类的 setter 方法进行属性赋值。
- 获取类的所有属性名称和类型，并为其中一个属性赋值。

## 5. 案例
- 购物网站系统，领导要求针对节假日设计不同优惠方案。
- 小王针对不同优惠方案编写对应实现类，并将类使用方法封装到系统代码中。
- 问题：代码耦合度高、维护成本大。
- 解决思路：使用反射降低耦合，运行时加载类、调用方法。

## 6. 总结
- Java 反射机制是 Java 语言被视为准动态语言的关键特性。
- 反射有优点也有缺点：
  - 优点：提高灵活性、降低耦合。
  - 缺点：性能开销、破坏封装、安全风险。
- 常见 API：Class、Method、Constructor、Field、Modifier。
