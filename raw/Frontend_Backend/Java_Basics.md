## 1. 变量
- 变量：一个数据存储空间的表示。
- 不同数据存入具有不同内存地址的空间，相互独立。
- 通过变量名可以简单快速找到数据。
- 变量命名规则：
  - 字、下、美、人、数、骆驼有意义。
  - 不能使用关键字，如 public、class。
  - 示例合法：`principal`、`$lastname`、`marks_3`。
  - 非法：`123rate`、`discount%`、`zip code`。

## 2. 数据类型
- 数值：
  - 整型：`int`、`byte`、`short`、`long`
  - 浮点型：`double`、`float`
- 非数值：`char`、`boolean`、`String`
- `String` 不是基本数据类型，是引用数据类型，Java 提供的一个类。
- 大小与范围：
  - byte 1字节 8位 -128~127
  - int 4字节 32位 -2^31~2^31-1
  - short 2字节 16位 -2^15~2^15-1
  - long 8字节 64位 -2^63~2^63-1
  - float 4字节 32位浮点数
  - double 8字节 64位浮点数

## 3. 变量声明及使用
1. 声明：`数据类型 变量名;`
2. 赋值：`变量名 = 数值;`
3. 合并：`数据类型 变量名 = 数值;`
4. 使用变量。

## 4. 常量
- 程序运行中值不能改变的量。
```java
final int NUM = 10;
final double PI = 3.14;
```
- 优点：安全。
- 推荐：常量名通常大写，不同字符用下划线分隔，只能赋值一次，通常定义时初始化。

```java
import java.util.*;

int now = input.nextInt();
```

## 6. 类型转换
### 6.1 自动类型转换
- 规则1：一个操作数为 double，整个表达式可提升为 double。
- 规则2：两种类型兼容，目标类型大于源类型。
- 数值类型整型和浮点型互相兼容。

### 6.2 强制类型转换
```java
int b = (int)10.2;
double a = 10;
int c = (int)a;
```

## 7. 运算符
### 7.1 赋值运算符
- `变量名 = 表达式;`
- 交换两个变量：
```java
int temp = num1; num1 = num2; num2 = temp;
```

### 7.2 算术运算符
- 基本：`+ - * / % ++ --`
- 复合：`+= -= *= /= %=`
- 示例：`5%2=1`，`5/2=2`。

### 7.3 关系运算符
- `== != > < >= <=`
- `=` 赋值，`==` 等于。
- 关系表达式结果为布尔值。
- `> < >= <=` 优先级高于 `== !=`。
- 只支持数值类型比较。

### 7.4 逻辑运算符
- `&&` 短路与：两个都 true 才 true。
- `||` 短路或：一个 true 就 true。
- `!` 非。
- 短路：第一个操作数能确定结果，第二个不计算。
- 优先级：`!` > `&&` > `||`。

### 7.5 条件运算符
```java
条件 ? 表达式1 : 表达式2
```
- 三元运算符。
- 示例：`min = 5 < 7 ? 5 : 7;`

### 7.6 优先级
- 单目 `! ++ --` 高。
- 算术 > 关系 > 逻辑。
- 赋值最低。
- `()` 最高。
- 从右向左：赋值、三目、单目。

## 8. 流程控制
### 8.1 if 选择结构
```java
if(条件){ // 代码块 }
```
- 条件结果必须是布尔值。
- 复杂条件使用逻辑运算符，复杂条件使用括号提高可读性。

### 8.2 if-else
```java
if(条件){ // 代码块1 } else { // 代码块2 }
```
- 只有一条语句也建议不省略 `{}`。

### 8.3 多重 if
```java
if(成绩>=80){ // 良好 }
else if(成绩>=60){ // 中等 }
else { // 差 }
```
- 适合连续区间判断。
- 注意条件顺序。

### 8.4 嵌套 if
- 外层语句和内层语句协作，增强灵活性。
- 字符串比较使用 `equals()`，如 `sex.equals("男")`。

### 8.5 switch
```java
switch (mingCi){
  case 1: ... break;
  case 2: ... break;
  default: ...
}
```
- 条件为等值判断。
- 每个 case 后不要忘记 break。
- default 块顺序可变动，通常放末尾，可省略。
- switch 只能处理等值条件；多重 if 适合连续区间。

## 9. 循环
### 9.1 while
```java
while(循环条件){ 循环操作 }
```
- 先判断，再执行。
- 循环四要素：初始部分、循环条件、循环体、更新循环变量。

### 9.2 do-while
```java
do { 循环操作 } while(循环条件);
```
- 先执行，再判断。
- 初始情况不满足条件时，do-while 至少执行一次。

### 9.3 for
```java
for(参数初始化; 条件判断; 更新循环变量){ 循环操作 }
```
- 循环次数确定时通常用 for。
- 常见错误：缺少循环条件、循环变量不变化、缺少循环控制导致死循环。

### 9.4 多重循环
- 一个循环体内又包含另一个完整循环结构。
- 外层循环变量变化一次，内层循环变量变化一遍。
- 一般不超过三层。
- 示例：九九乘法表。

### 9.5 break 与 continue
- break：终止某个循环，跳出循环执行后面语句；常用于 switch 和循环。
- continue：跳过本次循环剩余语句，进入下一次循环。
- return：结束当前方法执行并退出。

## 11. 数组
- 数组：存储相同数据类型的一组数据。
- 声明数组就是在内存空间划出一串连续空间。
- 基本要素：标识符、数组元素、元素下标（从0开始）、元素类型。
- 数组长度固定，避免越界。
- 使用四步：
  1. 声明数组：`int[] a;`
  2. 分配空间：`a = new int[5];`
  3. 赋值：`a[0]=8;`
  4. 处理数据。
- 声明并分配：`数据类型[] 数组名 = new 数据类型[大小];`
- 赋值：
  - 边声明边赋值：`int[] scores = {89,79,76};`
  - 动态键盘录入。
- 遍历：
  - `for(int i=0;i<scores.length;i++)`
  - 增强 for：`for(int score:scores)`
- 常见错误：没有写明数组大小、数组越界、创建数组并赋值必须一条语句完成。
- 求最大值：假设第一个为 max，循环比较。
- 插入数值：找到插入位置，元素后移，插入新成绩。

## 12. 冒泡排序
- 升序口诀：N 个数字来排队，两两相比小靠前；外层循环 N-1，内层循环 N-1-i。
- 每次比较相邻两数，小的交换到前面；每轮结束后最大的数交换到最后。
- 降序：改变比较方向。

## 14. 二维数组
- 语法：`数据类型[][] 数组名;` 或 `数据类型 数组名[][];`
- 定义时指定最大维数：`int[][] scores = new int[5][50];`
- 二维数组实际是以一维数组为元素的一维数组。
- 定义并赋值：
```java
int[][] scores = new int[][]{{90,85,92,78,54},{76,63,80},{87}};
int scores[][] = {{90,85,92,78,54},{76,63,80},{87}};
```
- 案例：3 个班级各 5 名学员，计算各班总成绩。
