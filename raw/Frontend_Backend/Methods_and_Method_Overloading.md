## 1. 带参数的方法
定义：
```java
<访问修饰符> 返回类型 <方法名> <形式参数列表> {
    // 方法主体
}
```
调用：
```java
对象名.方法名(参数1, 参数2, ..., 参数n);
```
- 实参列表。
- 常见错误：调用方法时不能指定实参类型；形参和实参数据类型、数量要一致。

## 2. 方法传参
- 基本数据类型：传递变量的值，改变一个变量不影响另一个。
- 引用数据类型（类、数组、接口）：传递原对象的引用（内存地址），可能影响原对象。
示例：
```java
public void calc1(int num){ num=num+1; }
public void calc2(Student student){ student.age=student.age+1; }
int n=8; test.calc1(n); // n 仍为 8
Student stu=new Student(); stu.age=18; test.calc2(stu); // stu.age=19
```

## 3. 构造方法
- 作用：对象初始化。
- 特点：
  - 无返回值类型。
  - 方法名与类名相同。
  - 可以指定参数。
  - 系统提供默认无参构造方法。
```java
访问修饰符 构造方法名() {
    // 初始化代码
}
```
- 构造方法重载：方法名相同，参数项不同；与返回值、访问修饰符无关。
- 自定义构造方法后，系统不再提供默认无参构造方法。

## 4. this 关键字
- 对一个对象的默认引用。
- 用法：
  - 调用属性：`this.health = 100;`
  - 调用方法：`this.print();`
  - 调用构造方法：必须是构造方法中的第一条语句。
- 用于区分同名成员变量。

## 5. 方法重载
- 同一个类中方法名相同，参数个数或类型不同。
- 与返回值、访问修饰符无关。
- 判断：
  - A：`method1()` 与 `method1(int i)` 是重载。
  - B：`public void method1()` 与 `public int method1()` 不是重载（仅返回值不同）。
  - C：`method1()` 与 `int method1(int i)` 是重载。

## 6. 成员变量和局部变量
- 作用域：
  - 局部变量：仅限于定义它的方法。
  - 成员变量：整个类内部可见。
- 初始值：
  - Java 给成员变量初始值。
  - Java 不给局部变量赋初始值。
- 同名：
  - 同一个方法中不允许同名局部变量。
  - 不同方法中可以有同名局部变量。
  - 成员变量和局部变量同名时，局部变量优先级更高。

## 7. 小结
- 基本类型和引用类型参数传递区别。
- 成员变量和局部变量区别。
- 方法重载特点。
- 构造方法作用与定义。
- this 用法。
