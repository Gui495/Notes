## 2. 人工智能三大要素
- 数据、算法、算力。
- 数据决定已有的先验信息。
- 算法作为桥梁，用于挖掘数据中的表征信息。
- 算力决定算法的效率。
- 三者共同驱动人工智能快速发展。
- AlphaGo 示例：
  - 数据：学习大量棋谱。
  - 算法：深度神经网络、蒙特卡洛树搜索。
  - 算力：1920 个 CPU + 280 个 GPU 的硬件配置；训练一次耗电量相当于一个家庭 10 年用电量。
- 数据是 AI 的“成长燃料”：数据质量越高、规模越大，AI 的“见识”就越广，能力越强；但也要注意数据质量、数据偏见。
- 算法是 AI 的“智慧配方”：策略网络预测落子位置，价值网络评估局面优劣；蒙特卡洛树搜索每步执行百万级模拟平行对弈，寻找最优落子位置。
- 算力是 AI 的“动力引擎”。

## 3. 搜索求解概述
- 人工智能中的搜索：从海量信息源中，根据约束条件和额外信息，寻找问题所对应答案。
- 示例：罗马尼亚地图最短路径问题，从 Arad 到 Bucharest。
- 搜索算法的形式化描述：<状态、动作、状态转移、路径、测试目标>。
  - 状态：从原问题转化出的问题描述；如城市。
  - 动作：从当前状态转移到下一状态的操作。
  - 状态转移：对某一状态执行动作后所能到达的状态。
  - 路径：一个状态序列，由一系列操作连接。
  - 目标测试：评估当前状态是否为求解目标状态。

## 4. 启发式搜索（有信息搜索）
- 在搜索过程中利用与求解问题相关的辅助信息。
- 代表算法：贪婪最佳优先搜索、A* 搜索。
- 辅助信息示例：任意城市与 Bucharest 之间的直线距离。
- 评价函数 \(f(n)\)：从当前节点 n 出发，根据评价函数选择后续节点。
- 启发函数 \(h(n)\)：计算从节点 n 到目标节点之间所形成路径的最小代价值；如两点直线距离。

### 4.1 贪婪最佳优先搜索
- 评价函数 \(f(n)=h(n)\)，只考虑启发函数。
- 示例：从 Arad 出发，按离 Bucharest 直线距离最小扩展。
- 不足：
  - 不是最优的，路径可能更长。
  - 对错误起点比较敏感；如从 Iasi 到 Fagaras，启发式建议先扩展 Neamt，但可能进入死循环路径。

### 4.2 A* 算法
- 评价函数：\(f(n)=g(n)+h(n)\)。
  - \(g(n)\)：从起始节点到节点 n 的实际最小代价。
  - \(h(n)\)：从节点 n 到目标节点的后续估计最小代价。
- 为保证 A* 最优，需满足：
  - 可容性：启发函数不会过高估计从 n 到目标的实际开销，即 \(h(n)\le\) 实际代价。直线距离可作为可容启发函数。
  - 一致性/单调性：假设 n 的后续节点是 n'，则 \(h(n)\le c(n,a,n')+h(n')\)。
- A* 在示例中逐步扩展，计算 \(g+h\)，最终得到最优路径。

## 5. 对抗搜索
- 又称博弈搜索：在竞争环境中，智能体之间通过竞争实现相反利益，一方最大化利益，另一方最小化利益。
- 类型：
  - 最小最大搜索 Minimax Search。
  - Alpha-Beta 剪枝搜索。
  - 蒙特卡洛树搜索。

### 5.1 Minimax 算法
- 给定游戏搜索树，通过每个节点的 minimax 值决定最优策略。
- MAX 希望最大化 minimax 值，MIN 相反。
- 公式：
  - 若终止状态：\(MINIMAX(s)=UTILITY(s)\)。
  - 若轮到 MAX：\(MINIMAX(s)=\max_{a} MINIMAX(RESULT(s,a))\)。
  - 若轮到 MIN：\(MINIMAX(s)=\min_{a} MINIMAX(RESULT(s,a))\)。
- 示例：根节点 MAX 选择 \(a_1\)，因为其 minimax 值最高。
- 优点：简单有效；对手“尽力而为”前提下返回最优结果。
- 缺点：搜索树极大时无法在有效时间内返回结果。
- 改善：Alpha-Beta 剪枝、采样而非逐一搜索。

### 5.2 Alpha-Beta 剪枝
- 在 Minimax 中减少搜索树节点数，结论与 Minimax 相同，但剪去不影响最终结果的分支。
- Alpha 值：MAX 节点目前得到的最高收益。
- Beta 值：MIN 节点目前可给对手的最小收益。
- 初始化 \(\alpha=-\infty,\beta=+\infty\)。
- 示例：根节点 MAX 的选择与某些 x、y 值无关，因此可剪枝。
- 通过剪枝减少访问节点。

### 5.3 蒙特卡洛树搜索 MCTS
- 利用与探索在游戏博弈树上的有机协调。
- 相关概念：
  - 单一状态蒙特卡洛规划：多臂赌博机。
  - 上限置信区间策略 UCB。
  - 蒙特卡洛树搜索。
- 多臂赌博机：k 种行动（k 个摇臂），每次摇动一个摇臂，获得随机收益；问题是如何选择使 n 次摇臂收益更高。
- 探索与利用平衡：
  - 利用 exploitation：保证在过去决策中得到最佳回报。
  - 探索 exploration：寄希望未来得到更大回报。
- 悔值函数：\(\rho_T=T\mu^*-\sum_{t=1}^T \hat r_t\)，良好策略使悔值方差最小。
- UCB 策略：选择具有最佳上限置信区间的赌博机：
  \[
  I_t=\max_{i\in\{1,\dots,k\}}\left(\overline{X}_{i,T(i,t-1)}+C\sqrt{\frac{2\ln t}{T(i,t-1)}}\right)
  \]
  平衡平均奖赏和选择次数。
- MCTS 四步骤：
  1. 选择 Selection：从根节点 R 开始，用 UCB1 递归选择子节点，直到叶子节点 L。
  2. 扩展 Expansion：若 L 不是终止节点，随机创建其后的一个未被访问节点 M。
  3. 模拟 Simulation：从 M 出发模拟游戏直到结束。
  4. 反向传播 Backpropagation：用模拟结果回溯更新路径上每个节点的获胜次数和访问次数。
- 两种策略学习机制：
  - 搜索树策略：从已有搜索树中选择或创建叶子结点，需要利用和探索平衡。
  - 模拟策略：从非叶子结点出发模拟游戏，得到仿真结果。
- 示例：围棋中节点记录 A/B，A 为胜利次数，B 为访问总次数；用 UCB1 计算选择。
- AlphaGo 解读：
  - 将每个状态局面视为图像。
  - 训练策略网络和价值网络。
  - \(p_{\sigma,\rho}(a|s)\)：当前状态 s 采取行动 a 的概率。
  - \(v_\theta(s')\)：当前状态 s' 整盘棋获胜概率。
  - 先基于监督学习训练策略网络，再基于强化学习训练策略网络。
  - 给定节点 v0，选择具有最大值的节点 v 作为后续：
    \[
    \frac{Q(v)}{N(v)}+\frac{P(v|v_0)}{1+N(v)}
    \]
  - 模拟阶段不仅考虑仿真结果，还考虑价值网络计算结果。
  - 策略网络和价值网络离线训练得到。

## 6. 逻辑与推理概述
- 逻辑与推理是人工智能核心问题。
- 人类智能关键标志：能够根据已知信息（知识），通过思考（推理），得出新结论或做出决策。
- 让机器模拟智能，必须赋予类似能力：从数据/知识中提取信息，并运用规则/逻辑生成新信息或行动。
- 逻辑是探索、阐述和确立有效推理原则的学科。
- 亚里士多德提出“三段论”，被誉为“逻辑学之父”。
- 墨子被认为是东方逻辑学奠基人，提出名、辞、说三种基本思维形式和故、理、类三物构成的逻辑推理；提出“平，同高也”“圆，一中同长也”。

## 7. 命题逻辑
- 命题逻辑：应用一套形式化规则对以符号表示的描述性陈述进行推理的系统。
- 原子命题：一个或真或假的描述性陈述，对内部结构不做解析。
- 示例：
  - p：北京是中国的首都（真）。
  - q：13 能被 6 整除（假）。
  - r：x<8（真假依赖 x，不是命题）。
  - s：存在最大的素数（假）。
  - t：\(m^2\ge 0\)（真）。
- 命题联结词：
  - 与 and：\(p\land q\)。
  - 或 or：\(p\lor q\)。
  - 非 not：\(\neg p\)。
  - 条件 conditional：\(p\to q\)，“如果 p 则 q”。
  - 双向条件 bi-conditional：\(p\leftrightarrow q\)，“p 当且仅当 q”。
- 真值表用于计算复合命题真假。
- 条件命题 \(p\to q\)：前提为假时命题为真；\(p\) 是 \(q\) 的子集，空集可被所有集合包含。
- 逻辑等价：p 和 q 在所有情况下真假结果相同，记 \(p\equiv q\)。
- 常用等价：
  - 逆否命题：\((\alpha\to\beta)\equiv(\neg\beta\to\neg\alpha)\)。
  - 蕴涵消除：\((\alpha\to\beta)\equiv(\neg\alpha\lor\beta)\)。
  - 德摩根定律：\(\neg(\alpha\land\beta)\equiv(\neg\alpha\lor\neg\beta)\)，\(\neg(\alpha\lor\beta)\equiv(\neg\alpha\land\neg\beta)\)。
- 推理规则：
  1. 假言推理：\(\alpha\to\beta,\alpha\Rightarrow\beta\)。
  2. 与消解：\(\alpha_1\land\cdots\land\alpha_n\Rightarrow\alpha_1,\dots,\alpha_n\)。
  3. 与导入：\(\alpha_1,\dots,\alpha_n\Rightarrow\alpha_1\land\cdots\land\alpha_n\)。
  4. 双重否定：\(\neg\neg\alpha\Rightarrow\alpha\)。
  5. 单项消解：\(\alpha\lor\beta,\neg\beta\Rightarrow\alpha\)。
  6. 消解：\(\alpha\lor\beta,\neg\beta\lor\gamma\Rightarrow\alpha\lor\gamma\)。
- 示例：已知 \(\alpha\lor\beta\)，\(\alpha\to\gamma\)，\(\beta\to\gamma\)，证明 \(\gamma\)；可用蕴涵消除、归结、反证。
- 不可满足示例：\(\alpha\lor\beta\)、\(\neg\alpha\lor\beta\)、\(\alpha\lor\neg\beta\)、\(\neg\alpha\lor\neg\beta\) 可推出 \(\beta\) 和 \(\neg\beta\)，因此不可满足。

## 8. 从命题逻辑到谓词逻辑
- 命题逻辑局限：原子命题是最基本单位，无法分解，不能表达局部与整体、一般与个别关系。
- 苏格拉底论断：
  - \(\alpha\)：所有的人总是要死的。
  - \(\beta\)：苏格拉底是人。
  - \(\gamma\)：所以苏格拉底是要死的。
  - \(\alpha\land\beta\to\gamma\) 不是命题逻辑有效推理。
- 需分析原子命题，分离主语（个体/群体）和谓语（关系），引入谓词逻辑。
- 谓词逻辑将原子命题细化为个体、谓词、量词，表达个体与总体的内在联系和数量关系。

## 9. 谓词逻辑
- 个体：谈论的具体对象，通常小写字母，如 s（苏格拉底）；是逻辑公式的主词，是属性和关系的承载者。
- 谓词：描述个体属性或个体间关系，通常大写字母，如 P、Q、R；如 \(Smart(s)\)、\(Love(john,mary)\)。谓词本身无真假，填入个体后才成为可判断真假的命题。
- 示例：
  - Richard 是国王：\(King(Richard)\)。
  - Lucy 和 Lily 是姐妹：\(Sister(Lucy,Lily)\)。
  - 北京是中国的首都：可符号化为二元谓词。
- 量词：
  - 全称量词 \(\forall\)：表示一切、凡是、所有、每一个；\(\forall xP(x)\) 表示定义域中所有个体具有性质 P。
  - 存在量词 \(\exists\)：表示存在、有一个、某些；\(\exists xP(x)\) 表示定义域中存在个体具有性质 P。
- 示例：
  - 所有国王都是人：\((\forall x)(King(x)\to Person(x))\)。
  - 所有国王都头戴皇冠：\((\forall x)(King(x)\to Head\_On(Crown,x))\)。
- 量词组合等价：
  - \(\forall x\neg P(x)\equiv\neg\exists xP(x)\)。
  - \(\neg\forall xP(x)\equiv\exists x\neg P(x)\)。
  - \(\forall xP(x)\equiv\neg\exists x\neg P(x)\)。
  - \(\exists xP(x)\equiv\neg\forall x\neg P(x)\)。
- 合式公式：按语法规则组装的合法逻辑表达式；组件包括原子公式、逻辑连接词、量词。
- 示例：
  - Tom 不仅喜欢踢足球，还喜欢打篮球：\(Like(Tom,Football)\land Like(Tom,Basketball)\)。
  - Tom 的所有同学都喜欢他：\((\forall x)(Classmate(Tom,x)\to Like(x,Tom))\)。
  - 不是所有男生都喜欢打篮球：\(\neg(\forall x)(Boy(x)\to Like(x,Basketball))\)。
  - 一个人是华侨，当且仅当他在国外定居并且具有中国国籍：\((\forall x)(oversea\_chinese(x)\leftrightarrow(oversea(x)\land chinese(x)))\)。
  - 男生都爱看世界杯：\((\forall x)(Boy(x)\to Like(x,worldcup))\)。
- 推理规则：
  - 全称量词消去 UI：\((\forall x)A(x)\to A(y)\)。
  - 全称量词引入 UG：\(A(y)\to(\forall x)A(x)\)。
  - 存在量词消去 EI：\((\exists x)A(x)\to A(c)\)。
  - 存在量词引入 EG：\(A(c)\to(\exists x)A(x)\)。
- 示例证明：已知 \((\forall x)(P(x)\to Q(x))\)、\((\forall x)(Q(x)\to R(x))\)，证明 \((\forall x)(P(x)\to R(x))\)。
- 自然语言形式化示例：
  - 每一个奇数均存在一个大于它的奇数：
    \[
    (\forall x)(odd(x)\to(\exists y)(odd(y)\land Great(y,x)))
    \]
  - 苏格拉底三段论：设 \(F(x)\) 表示 x 是人，\(G(x)\) 表示 x 是要死的，a 是苏格拉底。前提：\((\forall x)(F(x)\to G(x))\)，\(F(a)\)；结论：\(G(a)\)。证明用全称量词消去和假言推理。

## 10. 专家系统与知识图谱
- 专家系统构成：
  - 问题逻辑化（机器可理解）→推理机（专家系统）→答案输出。
  - 对某个领域的自然语言、文本语句等信息进行逻辑化。
  - 数据→知识→服务。
- 知识图谱定义：包含多种关系的图；节点是实体（人名、地名、事件、活动等），边表示关系。
- 三元组表示：\(（left\_node, relation, right\_node）\)，如 \(（David,Father,Mike）\)。
- 知识图谱构成：
  - 概念：层次化组织。
  - 实体：概念的示例化描述。
  - 属性：对概念或实体的描述信息。
  - 关系：概念或实体之间的关联。
  - 推理规则：可产生语义网络中新的元素。
  - 一般用标注多关系图表示。
- 示例家庭关系图：James、David、Ann、Mike 之间的 Couple、Mother、Father、Sibling 关系。
- 知识图谱推理：
  - 从 \(<奥巴马,出生地,夏威夷>\) 和 \(<夏威夷,属于,美国>\) 可推理得到 \(<奥巴马,国籍,美国>\)。
  - 问题：如何推理得到 \(father(David,Ann)\)？
  - 规则：\((\forall x)(\forall y)(\forall z)(Mother(z,y)\land Couple(x,z)\to Father(x,y))\)。
  - 可从具体例子中学习规则，属于归纳推理。
- FOIL（First-Order Inductive Learner）一阶归纳学习器：
  - 目标：给定已知正例和反例，自动归纳出一条或一组逻辑规则，尽可能准确区分正例和反例。
  - 正例：\(Father(David,Mike)\)。
  - 反例：\(Father(David,James)\)、\(Father(Ann,Mike)\)、\(Father(James,Ann)\)、\(Father(James,Mike)\)。
  - 流程：从一条规则开始，如 \(Couple(x,z)\)；不停给规则增加条件，如 \(Mother(z,y)\)，每次加一个最能提高准确率的条件；直到规则足够完美。
- 归纳逻辑程序设计 ILP：机器学习和逻辑程序设计交叉领域；使用一阶谓词逻辑进行知识表示，通过修改和扩充逻辑表达式对现有知识归纳，完成推理任务；可实现知识图谱扩充。

## 11. 本章小结
- 人工智能系统通过基本要素构建对世界的认知模型。
- 利用搜索求解技术高效寻找解决方案或达成目标。
- 借助逻辑与推理机制运用知识、得出结论、做出决策和解释行为。
- 三者紧密交织，构成 AI 实现智能行为（问题解决、规划、学习、决策）的核心方法论基础。
