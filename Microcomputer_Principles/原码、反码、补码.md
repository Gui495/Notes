 一、基础概念速记（8位字长为例）
 
码制 正数规则 负数规则 8位表示范围 
原码 最高位为符号位（0=正），其余位为数值本身 最高位为符号位（1=负），其余位为数值本身 -127 ~ +127 
反码 与原码相同 原码的数值位按位取反（符号位不变） -127 ~ +127 
补码 与原码相同 反码+1（符号位不变） -128 ~ +127（ 10000000 专门表示-128） 
 
 
  二、核心转换公式（必考）
 
1. 已知原码，求反码/补码
 
- 正数： 原码 = 反码 = 补码 
- 负数：-  反码 = 原码数值位按位取反 
-  补码 = 反码 + 1 （等价于：原码数值位取反+1）
 
2. 已知补码，求真值（最常用！）
 
- 第一步：判断符号位- 若最高位为 0 ：正数，补码=原码，直接转十进制
- 若最高位为 1 ：负数，用以下两种方法求原码：- 方法A： 补码 - 1 → 得到反码 → 数值位按位取反 → 得到原码 
- 方法B： 补码从右往左找第一个1，保留它和右边的0，左边所有位按位取反 （更快捷）
- 第二步：原码转十进制，加上负号就是真值
 
3. 已知反码，求真值
 
- 正数：反码=原码，直接转十进制
- 负数： 反码按位取反 → 得到原码 → 转十进制加负号 
 
4. 已知真值，求补码（比如第10题[-6]补）
 
- 正数：直接写原码即可
- 负数：1. 先写出绝对值的原码
2. 求反码（数值位取反）
3. 反码+1得到补码
 
 
  三、高频易错点&特殊值
 
1.  80H (10000000)  补码：8位补码中唯一没有对应原码的数，真值是 -128 ，不要算成-0！
2.  FFH (11111111)  补码：求原码时，减1得到 11111110 ，取反得到 10000001 ，真值是 -1 
3.  00H  和  FFH ： 00H  是 +0 ， FFH  是 -1 ，不要搞混
4. 十六进制转二进制技巧：1位十六进制=4位二进制，比如 E=1110 ， 5=0101 ，直接拼就行
