本页把数学侧的高斯积分、正态分布、边缘化，与人工智能侧的机器学习、神经网络接起来，并指出素材里真正缺的那一段——概率论与线性代数的基础推导。

## 两侧各自的存货

**数学侧**（3 篇素材）解决了一类计算：形如 ∫e^(−x²)dx 的积分怎么算出来。

- [[高斯积分]]：用极坐标把二重积分化成 ∫∫e^(−r²) r dr dθ，得到 √π，再经变量代换得到任意 σ 下的归一化常数。
- [[配方法]]：把指数上的二次式配成完全平方，才能套用标准积分。
- [[雅可比行列式]]：多元变量变换时密度要乘 |det J|，二维正态化成独立标准正态就靠它。
- [[二维正态分布]]与[[边缘概率密度]]：求边缘密度要把另一个变量积掉，而多元正态的边缘仍是正态——这是它能被大量使用的原因。

**AI 侧**（3 篇素材）讲了一门课的机器学习部分：

- 三要素（数据、算法、计算力）与六步流程（获取 → 处理 → 特征工程 → 训练 → 评估 → 上线），见 [[机器学习]]。
- 神经网络的结构与逐层抽象，见 [[神经网络]]、[[深度学习]]。
- 工程侧只有库的用法（numpy / pandas / matplotlib），见 [[2026-10-27-机器学习科学计算库]]。

## 四个接口

### 1. 高斯噪声 → 均方误差

线性回归为什么用 MSE 而不是别的？因为若假设观测值 = 真值 + 高斯噪声，那么最大似然估计等价于最小化残差平方和。素材里 MSE 是直接给出的，没有这层推导；而数学侧的[[高斯积分]]恰好提供了似然函数归一化的那一步。两侧拼起来，MSE 才不是「约定俗成」。

### 2. 协方差矩阵 → 特征工程

[[雅可比行列式]]处理的是「变量换元后密度怎么变」，PCA 处理的则是「协方差矩阵的特征分解」，两者都要求对矩阵做变换。素材里特征工程只写到「提取、预处理、降维」，降维的数学依据（协方差、特征值）在数学侧也没有专门素材——这是本库最明显的一处断链。

### 3. 边缘化 → 生成模型

[[2026-10-14-离散与连续随机变量的边缘分布]]给出的 P(X=x_i)=Σ_j p_ij 与 f_X(x)=∫f(x,y)dy，在深度学习里就是隐变量模型的目标函数：p(x)=∫p(x|z)p(z)dz。离散与连续的两种写法正好对应隐变量取离散值（如 VAE 的离散潜码）与连续值两种情形。素材没有把这两件事连起来，本页补上。

### 4. 反向传播 → 链式法则

素材讲了反向传播「用链式法则逐层求导」，但没有推导，也没有任何素材讲多元微积分。神经网络之所以能训练，靠的就是这层导数；缺了它，反向传播只能背流程。

## 素材缺口清单

| 缺口 | 现状 | 影响 |
|---|---|---|
| 线性代数（矩阵乘、特征值、SVD） | 全库无素材 | PCA、协方差、神经网络前向传播都只能「会用不会算」 |
| 概率论基础（期望、方差、条件分布） | 只有零散的边缘分布与正态密度 | 无法从似然推到损失函数 |
| 多元微积分（偏导、链式法则、梯度） | 全库无素材 | 反向传播只能背流程 |
| 数值稳定性（下溢、log-sum-exp） | 无 | 实际训练时会踩到但没人讲 |

前三条是本库的**结构性空洞**：数学侧停在「算积分」，AI 侧停在「调库」，中间那层推导没有人写。补素材时优先补线性代数与多元微积分两章，比再补一个框架的用法有价值。
