面向对象是一种以「对象」为基本单位组织程序的设计思想：把数据和对数据的操作捆绑在一起，由一个抽象的模板（类）描述同类事物，再由模板产生具体的个体（对象）去完成任务。

它与「结构化编程」的分野在于关注点的落点不同。结构化编程以「过程」为中心，程序是一系列按顺序执行的步骤，数据只是被步骤处理的对象；面向对象以「对象」为中心，先问「这个问题里有哪些事物、每个事物有什么属性、能做什么动作」，再让对象之间互相发消息协作。素材用「以过程为中心」与「以对象为中心」这一组对立来界定二者，并强调面向对象是更贴近现实世界思维方式的一种。

这一路抽象是逐层收窄的：现实世界的事物 → 抽取共同点得到**类**（抽象概念，不存在于内存中）→ 类实例化成**对象**（具体存在，占内存）。因此类与对象不是两个并列概念，而是同一条抽象链上的两端，详见 [[类与对象]]。

在 Java 语言里，「把数据和对数据的操作捆绑在一起」靠的是类的两个组成部分：描述状态的**成员变量**和描述行为的**成员方法**，两者共同构成一个能自我描述的单元；访问修饰符（`public` / `private`）决定这条边界对外的可见程度。素材的类图约定用 `+` 标 public、`-` 标 private，正是这种边界意识的图形化。

**素材边界**：这 9 篇 Java 素材只走到「类 + 对象 + 封装边界」这一步，**没有展开继承（`extends`）、接口（`implements`）与多态**——也就是说，面向对象通常被概括的那些特征里，素材只覆盖了封装的开端。阅读时不要把「面向对象」等同于素材给出的范围。
