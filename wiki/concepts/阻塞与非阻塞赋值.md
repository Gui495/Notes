阻塞赋值 `=` 按语句顺序立即生效，非阻塞赋值 `<=` 在块结束时同时更新；前者用于组合逻辑，后者用于时序逻辑。

## 分配规则

| 项目 | 时序逻辑 | 组合逻辑 |
|---|---|---|
| 敏感列表 | `posedge clk` / `negedge rst_n` | `always @(*)` |
| 赋值符号 | 非阻塞 `<=` | 阻塞 `=` |
| 综合结果 | 触发器/寄存器 | 纯组合逻辑 |
| 典型用途 | 计数器、状态机、流水灯 | 译码、简单逻辑运算 |

## 两条铁律

1. `always @(posedge clk)` 里**一律**用 `<=`。
2. `always @(*)` 里**一律**用 `=`，并且每个分支都要给输出赋值。

## 为什么不能用错

- 时序块里用 `=`：多条赋值按书写顺序串行生效，仿真与综合可能不一致，等效于人为制造竞争。
- 组合块里用 `<=`：仿真时输出延迟一个时间片，波形与真实组合逻辑不符。
- 组合块分支不全：综合工具推断出**锁存器**（`latch inferred`），是隐蔽的时序隐患。

## 标准写法

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        cnt <= 25'd0;
        led <= 1'b0;
    end else if (cnt >= CNT_MAX) begin
        cnt <= 25'd0;
        led <= ~led;
    end else begin
        cnt <= cnt + 1'b1;
    end
end
```

```verilog
always @(*) begin
    if (sel) y = a;
    else     y = b;
end
```
