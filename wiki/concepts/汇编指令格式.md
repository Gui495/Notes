汇编指令的书写格式为「标号: 操作码 操作数 ; 注释」；80x86 是**变长指令**体系，指令长度 1~16 字节。

## 指令与指令集

| 概念 | 含义 |
|---|---|
| 指令 | CPU 执行操作的基本单位，本质是「命令」 |
| 指令集 | CPU 能够执行的所有指令的集合 |
| 机器指令 | 二进制形式，CPU 唯一能直接识别 |
| 符号指令（汇编指令） | 助记符形式，便于人理解 |

转换关系：符号指令 →（汇编）→ 机器指令 → CPU 执行。

## 格式四要素

| 部分 | 作用 |
|---|---|
| 标号 | 地址符号，用于跳转 |
| 操作码 | 决定「做什么」（`ADD`、`MOV` 等） |
| 操作数 | 决定「对谁操作」 |
| 注释 | 说明，不参与执行 |

## 指令长度

- 80x86：**1 ~ 16 字节**，变长指令体系。
- 优点：节省存储空间。
- 缺点：译码复杂（相比 RISC 定长指令）。

## 指令存储

- 按字节连续存放。
- 多字节数据采用**小端方式**，详见 [[小端存储]]。

## 执行流程

取指 → 译码 → 取操作数 → 执行 → 写回 → 更新标志位。
