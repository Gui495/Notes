引脚约束把模块端口绑定到 FPGA 的真实引脚，位流是最终下载进芯片的配置文件；两者任一缺失，代码再正确板上也不工作。

## 必须约束的信号

- `clk`：系统时钟引脚。
- `rst_n`：复位按键引脚。
- `led` 或 `led[7:0]`：LED 引脚。

## 引脚号从哪来

1. 官方实验指导手册的「接口列表」「工程约束」章节。
2. 板卡原理图：找 FPGA 与 LED、晶振、复位按键相连的页码。
3. 官方例程自带的约束文件（PDS 工程常见 `.fdc` / `.uce`，以实际工程为准）。
4. PDS 的 User Constraint Editor 里手动添加。

> 不要照抄网上的引脚号——不同板卡版本可能不同。

## 下载九步

建/开工程 → 加 Verilog 源文件 → 设顶层模块 → 加引脚约束 → 综合 → 布局布线 → 生成位流 → 连下载器 → 下载观察。

## 约束不生效的常见原因

- 约束文件没加入工程；
- 引脚号写错；
- 改了约束但没重新综合和布局布线；
- 顶层模块选错（约束加在了非顶层上）。
