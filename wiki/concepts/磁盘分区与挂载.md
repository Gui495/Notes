磁盘分区与挂载是安装 Linux 时把物理磁盘切分为分区、建立文件系统、再挂载到目录树的过程；分区表与挂载点设计直接决定后续能否正常启动。

## 分区方案（UEFI + GPT 双系统示例）

| 分区 | 大小 | 类型 | 挂载点 |
|---|---|---|---|
| EFI 系统分区（ESP） | ≥ 260MB | FAT32 | `/boot`（或 `/efi`） |
| Root 分区 | ≥ 50GB | ext4 | `/mnt` |
| Home 分区 | 剩余空间 | ext4 | `/mnt/home` |

也可以直接复用 Windows 已有的 EFI 分区。

## 查看磁盘布局

```bash
lsblk      # 只显示已分配的分区
fdisk -l   # 显示完整分区表，含未分配空间
```

**易错**：`lsblk` 默认**不显示未分配区域**，因此在 Windows 中压缩出来但尚未建分区的空间不会出现在 `lsblk` 里，必须用 `fdisk -l` 查看。多块硬盘时还要靠容量与型号辨认目标盘，避免误操作 Windows 系统盘。

## 建分区工具

- `parted`：`mkpart primary fat32 起始 结束`、`set 分区号 esp on`
- `cfdisk` / `gdisk`：交互式；在空闲区 `[ New ]` 建分区，`[ Type ]` 改为 EFI System，`[ Write ]` 写盘

分区后**编号可能变化**，格式化前应再用 `lsblk` 或 `fdisk -l` 确认。

## 格式化与挂载

```bash
mkfs.fat -F32 /dev/nvme0n1pX   # ESP
mkfs.ext4 /dev/nvme0n1pY       # 根分区
mount /dev/nvme0n1pY /mnt
mount --mkdir /dev/nvme0n1pX /mnt/boot
```

`mount --mkdir` 等价于先 `mkdir -p` 再挂载；`mkdir -p` 的作用是**自动创建父目录**且**目录已存在时不报错**。

## Swap（交换空间）

相当于虚拟内存：物理内存不足时把暂不使用的数据移到硬盘腾出空间；同时是**系统休眠（挂起至磁盘）**的必需品。物理内存 ≥ 8GB 时可不建 Swap 分区，后续用 Swap 文件替代（更灵活）。

## 写入 fstab

```bash
genfstab -U /mnt >> /mnt/etc/fstab   # -U 表示用 UUID
cat /mnt/etc/fstab                   # 务必检查
```

fstab 规范：根分区挂载到 `/`，文件系统写 `ext4`，选项用 `rw,relatime`。

## 安全警告

> 磁盘上已有 EFI 分区时**不要重新格式化**，否则会破坏其他系统的引导。只有在新磁盘上创建全新 ESP 才可格式化。
