泛型（Generics）是把「数据的类型」也当作参数传入的机制，即参数化类型：定义时不写死元素类型，使用时再指定，从而在不写多份代码的前提下获得类型安全。

它解决的是一个具体痛点：没有泛型时，集合装 `Object`，放进去什么类型都行、取出来只能强转，类型错误要到运行期才暴露（`ClassCastException`）。加了泛型后，`List<Student>` 里只能放 `Student`，放错类型**编译期就报错**——把错误从运行期前移到编译期，这是泛型全部收益的主干。

Java 从 **JDK 5.0** 开始引入泛型，语法尖括号 `<>` 直接来自 C++ 模板的启发。使用上分两种：泛型类（在类名后声明类型参数，如 `class 类名<E>`）与泛型方法（在返回类型前声明类型参数）。

它能施加的约束是「元素类型」这一层：声明 `ArrayList<Student>` 后，`add` 只能接 `Student`，`get` 直接返回 `Student` 无需强转。它**不能**约束元素的数量、顺序或取值范围。

在 [[集合框架]] 里泛型是标配而非可选项，因为集合本身就是「装任意对象」的容器，正是最需要类型约束的地方。

**素材边界**：素材只讲到「约束元素类型 + 编译期报错」这一层，**没有涉及**通配符（`? extends` / `? super`）、类型擦除、泛型不能是基本类型（须用包装类）这些继续深入时必须面对的问题。
