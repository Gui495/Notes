## 课程定位

目标三条：了解机器学习的定义与应用场景；掌握基础环境安装与使用；用 Matplotlib、Numpy、Pandas 做数据展示与分析。它与 [[人工智能导论]] 不是同一门课，不应混为一章。

## 概念部分（与前八章重叠，可交叉验证）

- 三要素：数据、算法、计算力。计算力细分为 CPU（适合 IO 密集型）、GPU（适合计算密集型、易并行，SIMD 架构）、TPU。
- 关系：机器学习是 AI 的一个实现途径，[[深度学习]] 由机器学习发展而来。
- [[图灵测试]] 与 [[达特茅斯会议]] 的表述与 Chapter_1 一致，只是比例标准同样写成「超过 30%」（该 30% 已裁定为图灵原话的预测阈值、非共识判据，见 [[图灵测试]]）。
- 六个阶段：起步（1956—60 年代初）、反思（60—70 年代初）、应用（70 年代初—80 年代中，专家系统成功）、低速（80 年代中—90 年代中，专家系统问题暴露）、稳步（90 年代中—2010，深蓝、智慧地球）、蓬勃（2011 至今，大数据与 GPU）。
- 五个分支：CV、语音识别、文本挖掘/分类、机器翻译、机器人。

## 工作流程

获取数据 → 数据基本处理（缺失值、异常值）→ 特征工程（提取、预处理、降维）→ 训练 → 评估 → 上线或迭代。

数据集约定：一行一个样本、一列一个特征；目标是「特征值 + 目标值」或「只有特征值」；训练集 70%~80%，测试集 20%~30%。

评估：分类看准确率、精确率、召回率、F1、AUC；回归看 RMSE、RSE、MAE、RAE。拟合问题区分欠拟合（训练集特征关系都没学出来）与过拟合（训练好、测试差）。

## Jupyter Notebook

原名 IPython Notebook，开源 Web 应用，名字源自 Julia、Python、R；文件格式 `.ipynb`（JSON），适合把代码、叙事文本、可视化放在一起。启动 `jupyter notebook`，默认 `http://localhost:8888`。编辑模式（Enter）与命令模式（Esc）分开，`Shift+Enter` 执行并跳下一个 cell，`Ctrl+Enter` 执行并留下；命令模式 `Y`/`M` 切代码与 Markdown、`A`/`B` 上下插 cell。

## Matplotlib

三步流程：`plt.figure(figsize, dpi)` 建画布 → `plt.plot(x, y)` 绘图 → `plt.show()` 显示。

完善手段：刻度 `xticks/yticks`、网格 `grid`、标签 `xlabel/ylabel/title`、保存 `savefig`。**一个易踩的坑**：`plt.show()` 会释放 figure 资源，`savefig` 必须写在 `show` 之前。

中文显示需要设字体（`mpl.rcParams["font.sans-serif"]=["SimHei"]` 与 `axes.unicode_minus=False`）。多坐标系用 `subplots`，之后走面向对象接口（`axes[0].plot()`、`axes[0].set_title()`）。

五类图形与用途：折线（趋势）、散点（关联与离群点）、柱状（离散对比）、直方（连续分布）、饼图（占比）。

## Numpy

核心是 `ndarray`：同类型元素的 N 维数组，内存块风格（地址连续）、支持向量化、底层 C 实现可绕开 GIL。

常用属性：`shape`、`ndim`、`size`、`itemsize`、`dtype`。创建：`ones/zeros/ones_like/zeros_like`、`array`（深拷贝）与 `asarray`（浅拷贝）、`linspace`（定数量）与 `arange`（定步长）、`logspace`（等比）、随机（正态 `randn/normal/standard_normal`，均匀 `rand/uniform/randint`）。

索引先行后列；形状操作用 `reshape`（返回视图，行列不互换）、`resize`（改本身）、`T`；类型用 `astype`；去重 `unique`。逻辑用布尔索引、`all/any`、`where`、`logical_and/or`。统计用 `min/max/median/mean/std/var` 与下标 `argmax/argmin`，`axis=0` 按列聚合、`axis=1` 按行。

广播两条规则：后缘维度轴长相等，或其中一方长度为 1，如 `(4,1)+(3,)->(4,3)`。矩阵乘法 $(M,N)\times(N,L)=(M,L)$，不满足交换律、满足结合律；`np.matmul` 禁止矩阵与标量相乘，矢量内积时与 `np.dot` 无差别。

## Pandas

2008 年 Wes McKinney 开发，基于 Numpy，画图基于 Matplotlib。两种结构：Series（一维数据 + 索引）与 DataFrame（二维，行索引 index、列索引 columns）。多级索引用 MultiIndex；Panel 自 0.20.0 起弃用，改用 DataFrame + MultiIndex。

索引三种方式：直接索引先列后行；`loc` 先行后列按名字；`iloc` 先行后列按下标；`ix` 已弃用。排序 `sort_values` / `sort_index`。

运算与统计：`add/sub`、布尔筛选、`query`、`isin`、`describe`、`max/min/mean/std/var/median/mode`、`idxmax/idxmin/cumsum`、`apply`。

文件：CSV（`read_csv/to_csv`）、HDF5（`read_hdf/to_hdf`，需 `tables`，支持 blosc 压缩）、JSON（`read_json/to_json`，`orient` 取 split/records/index/columns/values）。缺失值：`isnull/notnull` 判断、`dropna` 删除（不修改原数据，需接返回值）、`fillna` 填充、`replace` 替换；`?` 这类非 NaN 标记要先替换成 `np.nan`。

离散化用 `cut`（自定义区间）与 `qcut`（等频），配合 `value_counts` 与 `get_dummies`（one-hot）。合并用 `concat`（按轴）与 `merge`（how 取 left/right/outer/inner）。交叉表 `crosstab`、透视表 `pivot_table`、分组聚合 `groupby`。

## 完整项目七步

抽象成数学问题（分类/回归/聚类）→ 获取数据（代表性、偏斜、量级）→ 特征预处理与选择（归一化、离散化、缺失值、去共线性；相关系数、卡方、互信息）→ 训练与调参 → 模型诊断（过拟合、交叉验证、学习曲线）→ 模型融合 → 上线运行（准确率、误差、时空间复杂度、稳定性）。

## 独立同分布

独立（每次抽样互不影响）+ 同分布（服从同一分布）= IID。它是「训练集效果好则测试集也好」的基本假设，但素材同时指出并非所有问题都要求 IID。

## 素材问题

1. **`axis` 的说法需要加一句**。素材写「axis=0 代表列，axis=1 代表行」，这是**结果视角**（按列聚合、结果以列为单位）；从操作视角看，`axis=0` 是沿行方向前进、跨行聚合。两种说法都对，但只写一句会让初学者在 `sum(axis=0)` 与 `drop(axis=0)` 之间混乱——后者的 axis=0 指删行。
2. **环境安装缺前置**。素材给的 `mkvirtualenv ai` 依赖 virtualenvwrapper，未说明需先安装；`pip3 install -r requirements.txt` 也未给 requirements 内容。属素材未展开。
3. **中文显示只适用于 Windows**。`SimHei` 是 Windows 字体，Linux/macOS 无此字体，照抄会继续显示方块。属素材未展开。
