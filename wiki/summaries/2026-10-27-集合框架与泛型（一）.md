对 [[raw/Frontend_Backend/Set_Framework_and_Generics1]] 的提炼：集合框架为什么要存在、`Collection` / `List` / `Set` / `Map` 的体系图、`ArrayList` 与 `LinkedList` 的结构性差异，以及 Iterator 与增强 for 两种遍历方式。

## 为什么有集合框架

- 数组**长度固定**：存少了浪费空间，存多了空间不足。
- 需要更复杂的存储方式（唯一性、键值映射、头尾操作）时，用集合框架。
- 集合位于 `java.util` 包。

## 体系结构

```
Collection ── List ── ArrayList / LinkedList     不唯一、有序（插入顺序）
           └─ Set  ── HashSet / TreeSet          唯一、无序
Map ── HashMap / TreeMap                          键值映射 key → value
工具类：Collections、Arrays
```

- 素材对 `Collection` 的定位写作「存储一组不唯一、无序的对象」——注意这是对**根接口**的概括，真正的顺序/唯一性由子接口决定：`List` 有序不唯一，`Set` 唯一无序。
- `Collections` 与 `Arrays` 是**工具类**，提供排序、遍历等算法；`Collections`（带 s）≠ `Collection`（接口）。

## ArrayList

- 底层是**长度可变的数组**，内存连续。
- 优势：遍历元素与随机访问（按下标取）效率高。
- 劣势：中间插入/删除可能要整体移动元素。

| 方法 | 说明 |
|---|---|
| `boolean add(Object o)` | 尾部追加 |
| `void add(int index, Object o)` | 指定位置插入 |
| `int size()` | 元素个数 |
| `Object get(int index)` | 按下标取 |
| `boolean contains(Object o)` | 是否包含 |
| `boolean remove(Object o)` / `Object remove(int index)` | 按对象删 / 按下标删（返回值不同，这是重载的典型例子） |

- `Collection` 通用方法：`clear()`、`isEmpty()`、`iterator()`、`toArray()`。

## LinkedList

- 底层是**链表**，元素不连续。
- 优势：插入、删除只需改指针；头部操作尤其快。
- 劣势：随机访问要从头走，慢。

| 方法 | 说明 |
|---|---|
| `void addFirst(Object o)` / `void addLast(Object o)` | 头 / 尾添加 |
| `Object getFirst()` / `Object getLast()` | 取头 / 尾 |
| `Object removeFirst()` / `Object removeLast()` | 删头 / 尾 |

## 二者怎么选

| 维度 | ArrayList | LinkedList |
|---|---|---|
| 存储 | 连续数组空间 | 链表节点 |
| 随机访问、遍历 | 快 | 慢 |
| 插入、删除 | 可能要移动元素 | 快 |
| 选型口诀 | **查多用 ArrayList** | **增删多用 LinkedList** |

## Set 接口

- 存**唯一、无序**对象；最常用实现 `HashSet`。
- Set 存放的是对象**引用**。
- 判断元素是否已存在，靠对象的 `equals()` 方法比较（不是 `==`）。
- Set **没有** `get()` 方法——没有下标，只能遍历。

## 两种遍历方式

```java
// Iterator
Iterator it = list.iterator();
while (it.hasNext()) { Object o = it.next(); }

// 增强 for
for (Object o : list) { ... }
```

- Iterator 三件套：`iterator()`、`boolean hasNext()`、`Object next()`。
- 增强 for 本质也是迭代器，但遍历中**不能**增删元素，且拿不到下标。

## 素材案例：新闻管理系统

- 需求：存新闻标题（ID、名称、创建者），取总数，逐条打印名称。
- 推理链：元素个数不确定 → 用集合；要遍历且元素类型固定为新闻标题；要头尾增删 → `LinkedList`；要随机访问与遍历 → `ArrayList`。
- 注意素材最后没给出「到底选了哪个」的结论，只给了两条判断依据。
