本章是《人工智能导论》第五章「深度学习」的笔记，从「为什么要深度学习」讲到神经元、反向传播、CNN 与其他典型网络，是 [[深度学习]] 与 [[神经网络]] 两页的主素材。

## 出发点：特征由谁来找

机器学习的问题是「如何通过特征工程构建最优特征」，深度学习的问题是「如何引导模型自主学习高判别性特征」。传统流程低水平检测 → 预处理 → 特征提取 → 特征选择 → 推理，每一段都要人；手工特征费力、启发式、依赖经验与运气。深度学习的答案是端到端、逐层抽象、逐层学习。

素材用视觉机理做支撑：视感觉阶段（视网膜采集、V1 区初步处理）负责把光信号转成神经信号；视知觉阶段与海马体记忆、杏仁核情感、前额叶注意力交互，把碎片整合成整体。抽象链条是：像素 → 边缘与方向 → 形状（圆形）→ 语义（人脸）。

## 逐层抽象的分工

输入层（像素化，类比感光细胞）→ 浅层隐藏层（边缘、角点、颜色，类比 V1）→ 中层（纹理、图案）→ 深层（部件，如眼睛轮廓、车轮形状）→ 全连接层（分布式特征映射到语义标签）→ 输出层（概率分布）。

对照「浅层学习」的分段流程（视觉词典 → 视觉单词 → 金字塔 → 直方图 → 分类），深度学习是「输入 → 逐层特征学习 → 输出」，靠卷积、池化与误差反向传播完成。

## 神经元与激活函数

人工神经元两步：$In=\sum W_i a_i$，$out=g(In)$。

无激活函数时 $y=Wx+b$，多层可合并为单层，只能处理线性可分数据。引入非线性才能拟合复杂函数，并保留「简单 → 复杂」的层级意义。

常见激活函数：Logistic $1/(1+e^{-x})$（导数 $f(1-f)$）、TanH（导数 $1-f^2$）、ArcTan（导数 $1/(x^2+1)$）、ReLU（负半轴取 0，导数 0 或 1）、PReLU（负半轴乘 $\alpha$）。

Softmax 不是激活函数而是输出归一化：$\sigma(z)_i=\frac{e^{z_i}}{\sum e^{z_j}}$，输出落在 (0,1) 且和为 1。素材算例 $x=[4,1,-4]$ → 约 0.9525 / 0.0471 / 0.0004；若输出为 [0.28,0.25,0.24] 说明模型判断不确定。

## 前馈网络与训练流程

前馈网络：层间全连接、层内不连接、无反馈；结构为输入层、隐藏层、输出层。感知机是无隐藏层的特例，$y=\phi(Wx+b)\in\{1,-1\}$，无法拟合复杂数据。

训练四步：前向传播 → 损失函数（回归平方损失、分类交叉熵）→ 反向传播分摊误差 → 梯度下降更新。优化器有 SGD、Mini-Batch GD、Adam、RMSProp。

梯度下降的数学依据：导数定义 → 多元梯度 → 泰勒展开 $f(x+\Delta x)-f(x)\approx(\nabla f)^T\Delta x$，要求 $(\nabla f)^T\Delta x<0$，即沿梯度反方向。

BP 算例（2-2-2 网络，8 个权重，Sigmoid）：前向得 $h_1,h_2,o_1,o_2$；误差 $\frac12\sum(o_i-y_i)^2$；链式法则求 $\delta_5=(o_1-y_1)\cdot o_1(1-o_1)\cdot h_1$；更新 $w_i'=w_i-\eta\delta_i$。

## CNN

设计源于生物视觉分级处理。结构：输入 → 卷积 → 特征图 → 池化 → 卷积 → 池化 → 全连接 → 输出。与前馈网络的关键差别是卷积核滑动、参数共享。

尺寸算例：7×7 经 3×3、步长 1 得 5×5；32×32×3 经 6 个 5×5×3 核得 6 张 28×28；再经 10 个 5×5×6 核得 24×24×10。池化用最大或平均，2×2 区域、步长 2。

AlexNet 规模：65 万神经元、6000 万参数、6.3 亿连接、4096 维特征层，双 GPU 训练约一周。目标检测时输出端同时产分类误差与包围盒误差。详见 [[卷积神经网络]]。

## 其他网络

- **RNN**：核心是循环体，$t$ 时刻读 $x_t$ 与 $h_{t-1}$ 生成 $h_t$，逐时刻推进至序列结束。
- **自编码网络**：编码器压到低维，解码器重建，去冗余与噪声；理想情况重建结果与输入几乎一致。
- **GAN**：生成器由随机噪声造样本，判别器判真假。
- **Transformer**：编码器-解码器 + 位置编码 + 多头注意力；自注意力 $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^T/\sqrt{d_k})V$，流程为 Embedding → Q/K/V → 打分 → 除 $\sqrt{d_k}$ → Softmax → 乘 V 求和。多头并行后拼接再做线性变换。它是 GPT、BERT 的基础架构，见 [[2026-10-27-大语言模型与低空经济]]。

## 素材问题

1. **AlexNet「超越人类」有误**。原文称 2012 年 AlexNet 图像识别正确率超越人类；实际 top-5 错误率 15.3%、人类基线约 5.1%，未超越（首个低于人类基线的是 2015 年 ResNet 约 3.57%）。证据：ILSVRC 2012 官方冠军成绩、ILSVRC 2015 论文的人类标注实验。已裁定，raw 不改，订正记在 [[深度学习]]。
2. **「无激活函数 vs softmax」的对照不成立**。两者不是同一层的替代关系：无激活函数说的是网络缺非线性，softmax 说的是输出层概率归一化。素材并列比较会让读者以为「加了 softmax 就有了非线性」。
3. **数值取整不一致**。softmax 算例给 0.9525 / 0.0471 / 0.0004，按 $e^4/e^1/e^{-4}$ 直算为 0.9523 / 0.0474 / 0.0003，属四舍五入差异，不影响结论。
