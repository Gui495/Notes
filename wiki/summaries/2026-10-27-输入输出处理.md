对 [[raw/Frontend_Backend/Input_and_Output_Processing]] 的提炼：File 对象与流的两套分类（流向 / 处理单元）、字节流与字符流的读写套路、缓冲流与编码、二进制文件与序列化。素材本身是「（一）（二）」两篇的合订。

## 输入输出与 File

- 数据流向：文件 / 内存 / 键盘 → **程序** → 文件 / 内存 / 控制台。
- 访问文件**属性**用 `java.io.File`，不负责读写内容。

```java
File file = new File(String pathname);
```

| 方法 | 作用 |
|---|---|
| `boolean exists()` | 文件或目录是否存在 |
| `boolean isFile()` / `boolean isDirectory()` | 类型判断 |
| `String getPath()` / `getAbsolutePath()` / `getName()` | 路径名 / 绝对路径 / 名称 |
| `boolean delete()` | 删除文件或目录 |
| `boolean createNewFile()` | 创建空文件（**不创建文件夹**） |
| `long length()` | 字节长度，不存在返回 `0L` |

## 流的两套分类

- 流：一组有序的数据序列，以先进先出方式发送信息的通道。
- **按流向**：输入流（数据源 → 程序，基类 `InputStream` / `Reader`）、输出流（程序 → 目的地，基类 `OutputStream` / `Writer`）。
- **按处理单元**：字节流（8 位通用字节，`InputStream` / `OutputStream`）、字符流（16 位 Unicode，`Reader` / `Writer`）。
- 方向是**相对计算机内存**说的，这是判断「读还是写」的唯一坐标。

## 字节流读写文本

| | FileInputStream | FileOutputStream |
|---|---|---|
| 常用方法 | `read()`、`read(byte[] b)`、`read(byte[] b,int off,int len)`、`close()`、`available()` | `write(int c)`、`write(byte[] buf)`、`write(byte[] b,int off,int len)`、`close()`、`flush()` |
| 构造 | `(File)`、`(String name)` | `(File)`、`(String name)`、`(String name, boolean append)` |
| 注意 | `available()` 返回可读字节数 | 前两种构造**覆盖**原内容；文件不存在会自动创建空文件 |

固定四步：引入类 → 构造流对象 → 读写 → 关闭。

## 复制文件的两个坑

- 坑一：循环里读了两次（`while((len = fis.read(buf)) != -1)` 只读一次）。
- 坑二：写入时用了缓冲区长度而不是**实际读取长度** `len`，文件尾部多出空格。
- 正确姿势：按实际读到的 `len` 读、按 `len` 写。

## 字符流

| | 读 | 写 |
|---|---|---|
| 基类 | `Reader`：`read()`、`read(char[] c)`、`read(char[] c,int off,int len)`、`close()` | `Writer`：`write(String str)`、`write(String str,int off,int len)`、`close()`、`flush()` |
| 桥接类 | `InputStreamReader(InputStream in [, String charsetName])` | `OutputStreamWriter(OutputStream out [, String charsetName])` |
| 便捷子类 | `FileReader(File)` / `FileReader(String)` | `FileWriter(File)` / `FileWriter(String)` |
| 缓冲子类 | `BufferedReader(Reader in)`，特有 `readLine()` | `BufferedWriter(Writer out)` |

- `FileReader` 是 `InputStreamReader` 的子类，`FileWriter` 是 `OutputStreamWriter` 的子类。
- 关键限制：`FileReader` / `FileWriter` **只能按本地平台字符编码**读写，不能指定其他编码。
- 查本地编码：`System.getProperty("file.encoding")`。
- **中文乱码解法**：绕开 FileReader，用 `FileInputStream` + `InputStreamReader(fis, "UTF-8")` + `BufferedReader`。
- 关闭顺序：先关外层（缓冲流），再关内层。

## 二进制文件

- `DataInputStream` 与 `DataOutputStream` 分别配合 `FileInputStream` / `FileOutputStream` 读写二进制（素材示例写 `C:\temp.class`）。
- 素材练习：复制图片 `star.jpg`。
- 注意与文本的差别：二进制复制**不要**经过字符流，否则字节会被编码转换破坏。

## 序列化与反序列化

- 场景：对象要跨环境传（网络需二进制序列）或跨时间用（持久化到磁盘）。
- 方案对比：Java 内置 `Serializable`、XML（跨平台跨语言）、JSON（属性-值，协议简单解析快）、Thrift（RPC，空间与解析性能）、Avro（自描述，广泛用于 Hive / Pig / MapReduce）。

| | 序列化 | 反序列化 |
|---|---|---|
| 动作 | 把对象状态写入特定流 | 从流中取数据重建对象 |
| 步骤 | ① 实现 `Serializable` ② 建对象输出流 ③ `writeObject()` ④ 关流 | ① 实现 `Serializable` ② 建对象输入流 ③ `readObject()` ④ 关流 |

- 用集合保存对象，可一次性序列化集合里所有对象。
- 向同一文件写入多个对象时，反序列化**必须按写入顺序**读取。
