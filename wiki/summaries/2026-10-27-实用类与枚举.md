对 [[raw/Frontend_Backend/Practical_Introduction]] 的提炼：枚举如何把「一组固定常量」变成类型、八种包装类的构造与四个转换方法、装箱拆箱，以及 `Random` 与 `String` 的高频操作。素材是「（一）（二）」两篇合订。

## 枚举

- 枚举是由**一组固定常量**组成的类型。

```java
[Modifier] enum enumName {
    enumConstantName1 [, enumConstantName2 ... [:]]
    // [field, method]
}

public enum Genders { Male, Female }
public class Student { public Genders sex; }

Student stu = new Student();
stu.sex = Genders.Male;
// stu.sex = "你好";   // 编译错误
```

- 好处：**类型安全**（取值只能是列出的常量，编译器把关）、易于输入（IDE 提示）、代码清晰。
- 素材案例：把大数据岗位课程按 L1 / L2 / L3 三阶段建模，输出学习目标。

## 包与 API 地图

- `java.lang`：`Enum`、包装类、`Math`、`String`、`StringBuffer`、`System`——自动导入。
- `java.util`（集合、`Random`）、`java.io`（流）、`java.sql`（数据库）。
- 学习方法：查 Java API 文档。

## 包装类

- 作用：把基本类型数据**包成对象**。
- 两个用途：① 提供一串实用方法；② **集合不允许存放基本数据类型**，存数字必须用包装类型（这条直接解释了 [[2026-10-27-集合框架与泛型（一）|集合]] 为什么收的是 `Object`）。
- 继承结构：

```
Object ── Boolean / Character / Number ── Byte / Short / Integer / Long / Float / Double
```

### 构造方法

- 每个包装类都能用**对应基本类型**作参数：`Integer i = new Integer(1);`
- 除 `Character` 外，都能用**字符串**作参数：`Integer i = new Integer("123");`
- 注意：`Boolean` 用字符串构造时，内容为 `true`（忽略大小写）才得 true，其余一律 false，不报错。
- 注意：`Number` 系包装类用字符串构造时，字符串不能为 `null`，且必须能解析成对应基本类型，否则运行期 `NumberFormatException`。

### 四个转换方法

| 方向 | 方法 | 例 |
|---|---|---|
| 包装类 → 基本类型 | `XXXValue()` | `integerId.intValue()` |
| 基本类型 → 字符串 | `toString()` | `Integer.toString(25)`、`Character.toString('男')` |
| 字符串 → 基本类型 | `parseXXX()`（`Character` 除外） | `Integer.parseInt("36")`、`Boolean.parseBoolean("false")` |
| 基本类型 → 包装类 / 字符串 → 包装类 | `valueOf()`（`Character` 除外支持字符串） | `Integer.valueOf(21)` |

### 装箱与拆箱

```java
Integer intObject = 5;   // 装箱：基本类型 → 包装类对象
int intValue = intObject; // 拆箱：包装类对象 → 基本类型
```

- JDK 1.5 起允许基本类型与包装类型混合做数学运算（自动拆箱）。
- 定位提醒：包装类**不是**用来取代基本类型的，只在「基本类型需要用对象表示时」才用（入集合、可空表达）。

## Math 类

- `java.lang.Math` 提供常用数学运算与两个静态常量 `E`、`PI`。

```java
Math.abs(-3.5);                        // 3.5
Math.max(2.5, 90.5);                   // 90.5
int random = (int)(Math.random()*10);  // 0-9，注意左闭右开
```

## Random 类

```java
Random rand = new Random();
int num = rand.nextInt(10);   // 0-9
```

- 用**同一个种子值**初始化两个 `Random` 对象，再用相同方法调用，会得到相同的随机序列——这是「伪」随机。

## String 类

- 位于 `java.lang`，创建方式：字面量 `"Hello World"` 或 `new String()`。

### 比较：`equals()` vs `==`

| 写法 | 比的是什么 |
|---|---|
| `equals()` | 组成字符串的**字符内容**是否完全一致 |
| `==` | 两个字符串在内存中的**地址**，即是否同一个对象 |

- 所以判空/判等一律用 `equals()`；忽略大小写用 `equalsIgnoreCase()`。
- 配套：`toLowerCase()` / `toUpperCase()`。

### 其它常用操作

| 目的 | 方法 | 要点 |
|---|---|---|
| 长度 | `length()` | 字符数（注意与数组的 `length` 属性区分） |
| 连接 | `+` 或 `concat()` | `"Hello, ".concat("World")` |
| 查找 | `indexOf(...)` / `lastIndexOf(...)` | 首次 / 末次出现位置，**找不到返回 −1** |
| 截取 | `substring(int index)` / `substring(int begin, int end)` | 从某位置到末尾 / 取两位置之间 |
| 去空格 | `trim()` | 去掉前后空格，返回**副本** |

素材示例 `s.substring(index1+1, index2)` 的用法可反证：`end` 是**不含**的那一端，否则会把 `!` 也取进来。

## 素材缺失

- `substring(begin, end)` 只说「提取 begin 和 end 之间的部分」，**没写 end 下标不包含**，也没写越界会抛 `StringIndexOutOfBoundsException`。
- 未涉及 `String` 的不可变性、`split()`、`StringBuilder`（只在别篇的线程安全对照里露面）。
- 枚举只讲了最简形态，未讲带字段/构造方法/方法的枚举，也未讲 `values()`、`valueOf()`、`switch` 配合。
