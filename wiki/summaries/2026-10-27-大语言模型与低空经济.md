本章是《人工智能导论》第八章「发展与挑战」的笔记，三条线：大语言模型、AI 在通信领域的应用、低空经济，末尾收在伦理与人的能力上。

## 政策背景

2017 年《新一代人工智能发展规划》提出「三步走」：2020 年总体技术与应用与世界先进水平同步；2025 年基础理论重大突破、部分技术与应用世界领先；2030 年总体达到世界领先水平、成为世界主要 AI 创新中心。

后续时间线：2019 年产业发展三年行动计划、2020 年标准体系建设指南、2021 年伦理规范、2022 年示范应用场景通知、2024 年「人工智能+」首次进入政府工作报告、2025 年十四届全国人大三次会议提出持续推进「人工智能+」行动。

## 大语言模型

概念链：数据 → 统计学 → [[机器学习]]；数据 → 神经网络 → [[深度学习]]；数据 → 大语言模型 → 生成式 AI。LLM 是专注自然语言处理（NLP）与生成（NLG）的基础模型，规模体现在参数、训练数据、算力三方面。

发展节点：2017 年 Google《Attention is all you need》提出 Transformer；2018 年 GPT-1 与 BERT；2020 年 GPT-3（1750 亿参数）开启大模型时代；此后 Llama 2（700 亿）、DeepSeek（6710 亿）、微软 Phi-4。

**技术逻辑**是本章最实用的一段：大模型并不真正「理解」语言，回答更像词语接龙，核心是逐步推测下一个最可能的 token。流程：

1. 分句为 token 序列。粒度越细泛化越好但 token 更多、算力更贵；粒度越粗保留语义更多但遇生词与多义词会失效。
2. 转成向量，即 Embedding。
3. 以 Embedding 形式输出字典中每个 token 的概率，实现「接龙」。
4. 编码器建模语义关系，解码器逐步生成。示例：「周末去西湖」之后「看」49%、「散步」28%、「边」22%、「落日」1%。
5. 迭代预测直到完整序列或停止条件。

选词策略两种：贪婪搜索（取概率最高）与按分布随机采样——后者让每次生成不同，接近人类语言的多样性。

**三类优化手段**：

| 手段 | 做法 | 代价 |
|---|---|---|
| 提示词工程 | 用指令、主体内容、指引、附加内容、样例把问题问准 | 无训练成本，但依赖使用者 |
| 微调 | 全微调（更新全部参数，效果最好）或 LoRA（只调少量参数、冻结原权重） | 耗算力、耗时数天，知识更新频繁时成本高 |
| RAG | 生成前检索外部知识库，把知识塞进上下文 | 需维护索引与检索质量 |

RAG 的三段流程：索引（分块 → Embedding → 向量索引 → 存储）、检索（查询向量化 → 向量检索）、生成（查询 + 附加信息 → 提示 → 输出）。变体有 Graph RAG（按知识图谱组织，抽取图谱 → 社区识别 → 社区摘要 → 向量化）与引入 Agent 反馈的多轮检索。

素材也点出了**幻觉**的成因：知识与训练数据绑定，问「西湖今天有没有下雨」这类训练中不存在的事实，模型可能直接编。

## AI 在通信领域

智能通信的定义是让网络像人一样有大脑，实现自感知、自优化、自修复、自主运营。ITU-R 6G 时间线：2020—2023 技术趋势与愿景、2024—2026 需求与频谱、2026—2027 提交与评估、2028—2030 规范。

5G/6G 中的落点：3GPP SA2 网络自动化、SA5 数据分析服务、RAN 侧 SON/MDT 数据收集与 AI/ML 功能框架、空口研究（CSI、定位、波束管理、移动性）；核心网侧 NWDAF 收集分析数据指导网络运行。

四类具体价值：信号传输（衰减畸变预测、联合信源信道编码、干扰指纹识别）、能效管理（流量预测、基站动态休眠、温控预判、低流量时段节能）、运维（流量预测、故障定位、自适应调度）、卫星与遥感（动态资源调度、星载计算、多模态遥感融合）。

## 低空经济

定义：低空空域（地面到 1000 米）内开展的一系列商业活动与经济行为。政策见《国家综合立体交通网规划纲要》《通用航空发展「十四五」规划》，地方以深圳、成都示范区为代表，企业侧有大疆、吉利沃飞长空、小鹏飞行汽车、亿航。

应用：低空旅游、载人飞行、空中摄影、物流配送、航空运动、电力巡检、吊装、远航运输、水源环境监测。AI 的落点是路径规划与避障、自动化调度、需求预测；城市场景的核心载体是 eVTOL（载人级无人驾驶电动垂直起降航空器）。

## 伦理与人的位置

伦理七关注：人类自主性与监督、技术稳健性与安全、隐私与数据治理、透明度、多样性与非歧视、社会与环境福祉、问责制。素材用加拿大航空客服聊天机器人事件说明 AI 回答错误会直接带来责任问题。

另一组是**主体性**风险：过度依赖 AI 情感陪伴导致社交能力退化、技术性孤独与焦虑、对人类情感价值的贬低。

对人的建议三条：成为 AI 的掌控者；持续学习（终身学习、跨学科、数字素养）；发展创造力与批判性思维（设计思维）；提升社交与情商（沟通、领导力、跨文化）。

## 素材问题

1. **Phi-4 参数量错了一个数量级**。原文写「微软 Phi 4、14 亿参数模型」，正确值是 **140 亿（14B）**。判定依据：①微软 Phi-4 技术报告标注 14B；②同句前文说「参数量越大通常性能越强……小语言模型反而更具性价比」，若 Phi-4 只有 14 亿，它就不该被拿来和 Llama 2（700 亿）、DeepSeek（6710 亿）并列讨论「性价比」——14 亿属极小模型，与「小语言模型」这一档次的常见下限也不符。
2. **参数量口径不统一**。Llama 2 有 7B/13B/70B 三个规格，素材只取最大的 700 亿且未说明，读者会误以为 Llama 2 只有一种规模。DeepSeek 6710 亿对应 V3，素材同样未标型号。
3. **无法核实的具体数字**：低空经济「2030 年 2 万亿元、2035 年超过 5.1 万亿元」为预测值，素材未给出处与统计口径；「通信行业碳排放占全球约 4%」常见口径是 ICT 全行业（含终端与数据中心），单算通信网络通常低于该值，素材未区分。两条均标**待核**，不作定论。
4. **「LLM 是生成式 AI 的基础」表述松散**。更准确的表述是 LLM 属于生成式 AI（或作为 foundation model 支撑上层应用），素材的箭头「数据 → LLM → 生成式 AI」把因果与从属混在了一起。
