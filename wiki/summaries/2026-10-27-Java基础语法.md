对 [[raw/Frontend_Backend/Java_Basics]] 的提炼：Java 语言层的基础积木——变量与八种基本类型、类型转换、运算符优先级、流程控制、数组与冒泡排序。这一篇是整条 Java 线的地基，后续 [[2026-10-27-类与对象]] 才把「类」引入。

## 变量

- 变量是一块**命名过的存储空间**；不同数据落在不同内存地址，互相独立，靠变量名定位。
- 命名口诀「字、下、美、人、数、骆驼」：字母、下划线、美元符、人民币符号、数字、驼峰有意义。
- 不能使用关键字（`public`、`class`）。
- 合法：`principal`、`$lastname`、`marks_3`；非法：`123rate`、`discount%`、`zip code`。

## 数据类型

| 类型 | 字节 | 位 | 范围 / 说明 |
|---|---|---|---|
| `byte` | 1 | 8 | −128 ~ 127 |
| `short` | 2 | 16 | −2^15 ~ 2^15−1 |
| `int` | 4 | 32 | −2^31 ~ 2^31−1 |
| `long` | 8 | 64 | −2^63 ~ 2^63−1 |
| `float` | 4 | 32 | 32 位浮点数 |
| `double` | 8 | 64 | 64 位浮点数 |
| `char` | — | — | 非数值型，素材未给位数 |
| `boolean` | — | — | 非数值型，素材未给位数 |

- 基本类型共 8 种，分**数值**（整型 4 种 + 浮点型 2 种）与**非数值**（`char`、`boolean`）。
- `String` **不是**基本类型，是引用类型，是 Java 提供的一个类——这条区别直接决定了后面 `==` 与 `equals()` 的分工（见 [[2026-10-27-实用类与枚举]]）。

## 变量声明三步

1. 声明 `数据类型 变量名;`
2. 赋值 `变量名 = 数值;`
3. 合并 `数据类型 变量名 = 数值;`，然后使用。

## 常量

```java
final int NUM = 10;
final double PI = 3.14;
```

- 运行期不可改，优点写「安全」；只能赋值一次，通常定义时初始化；命名习惯全大写 + 下划线分隔。

## 类型转换

| 方向 | 条件 | 例 |
|---|---|---|
| 自动（隐式） | ① 有一个操作数为 `double` 则整式提升 ② 两类型兼容且目标类型更宽 | `double a = 10;` |
| 强制（显式） | 窄化，必须写 `(类型)` | `int b = (int)10.2;` → 10，**截断不是四舍五入** |

整型与浮点型互相兼容；其余不兼容的类型不能互转。

## 运算符

| 类别 | 符号 | 要点 |
|---|---|---|
| 赋值 | `=` | 交换两变量需第三方 `temp` |
| 算术 | `+ - * / % ++ --`、`+= -= *= /= %=` | `5/2=2`（整除）、`5%2=1` |
| 关系 | `== != > < >= <=` | 结果是布尔值；`=` 是赋值、`==` 才是等于 |
| 逻辑 | `&& \|\| !` | 短路：前一个操作数已定结果则不算第二个 |
| 条件 | `条件 ? 表达式1 : 表达式2` | 三元运算符，如 `min = 5 < 7 ? 5 : 7;` |

优先级：`()` > 单目 `! ++ --` > 算术 > 关系 > 逻辑 > 赋值；结合方向从右向左的是赋值、三目、单目。

## 流程控制

- `if`：条件必须是布尔值；复杂条件用 `()` 提高可读性。
- `if-else`：即使只有一条语句也建议保留 `{}`。
- 多重 `if`：适合**连续区间**判断，注意条件顺序（先宽后窄会吃掉后面的分支）。
- 嵌套 `if`：字符串比较用 `equals()`，如 `sex.equals("男")`。
- `switch`：只做**等值**判断；每个 `case` 别忘 `break`；`default` 位置可变、可省略。区间判断只能用多重 `if`。

## 循环

| 结构 | 语义 | 适用 |
|---|---|---|
| `while` | 先判断，再执行 | 次数不确定 |
| `do-while` | 先执行，再判断 | 至少执行一次 |
| `for` | 初始化; 条件; 更新 | 次数确定 |

- 循环四要素：初始部分、循环条件、循环体、更新循环变量；缺任一都会死循环或零次执行。
- 多重循环：外层变量变一次，内层跑一遍；一般不超过三层（九九乘法表）。
- `break` 跳出本层循环；`continue` 跳过本次剩余语句进入下一次；`return` 直接结束当前方法。

## 数组

- 数组是**相同数据类型**的一组元素，声明即在内存划出一串连续空间。
- 四要素：标识符、数组元素、元素下标（从 0 开始）、元素类型。
- 使用四步：声明 `int[] a;` → 分配 `a = new int[5];` → 赋值 `a[0]=8;` → 处理。
- 声明并赋值必须**一条语句**完成：`int[] scores = {89,79,76};`
- 两种遍历：`for(int i=0;i<scores.length;i++)` 与增强 for `for(int score:scores)`（后者取不到下标）。
- 常见错误：没写数组大小、下标越界、声明与赋值拆成两条却用 `{…}`。
- 两个典型套路：求最大值（先假设第一个为 max 再逐个比较）；插入数值（找位置 → 元素后移 → 插入）。

## 冒泡排序

- 升序口诀：N 个数字来排队，两两相比小靠前；**外层循环 N−1，内层循环 N−1−i**。
- 每轮把当前最大值「冒」到末尾；降序只改比较方向。

## `java.util.Arrays` 工具类

| 方法 | 作用 |
|---|---|
| `boolean equals(a1,a2)` | 比较两数组内容 |
| `sort(array)` | 升序排序 |
| `String toString(array)` | 转成可打印字符串 |
| `void fill(array,val)` | 全部填同一值 |
| `copyOf(array,length)` | 复制并指定新长度 |
| `int binarySearch(array,val)` | 二分查找，**要求数组已升序** |

## 素材订正（已裁定）

**原文错值**：§7.3「关系运算符……只支持数值类型比较」。

**正确值**：`> < >= <=` 只能用于数值类型；但 `==` 与 `!=` 还能用于 `boolean` 与引用类型（比较引用是否指向同一对象）。

**判定证据**：① 同一素材 §8.4 自己就要求字符串用 `equals()` 而非 `==`，说明 `==` 能作用于非数值类型，否则无需专门警告；② 后面 [[2026-10-27-实用类与枚举]] 的 String 部分也把 `==` 解释为「判断两个字符串在内存中的地址」，既然 `==` 能用于字符串，「只支持数值类型」即不成立。

## 素材缺失

- `char` 与 `boolean` 的位数未给出（`char` 按 Java 规范是 16 位 Unicode，但素材未写，此处不代补）。
- 全篇没有异常处理、没有方法定义——方法与类分别见 [[2026-10-27-方法与重载]]、[[2026-10-27-类与对象]]。
