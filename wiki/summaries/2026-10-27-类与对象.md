对 [[raw/Frontend_Backend/Classes_and_Objects]] 的提炼：从结构化开发转向面向对象的理由、对象的三要素、类与对象的关系，以及定义类、画类图、创建对象的完整套路。

## 为什么换范式

| 范式 | 划分依据 | 最小子系统 | 后果 |
|---|---|---|---|
| 结构化开发 | 按**功能**自顶而下划分 | 方法 | 需求一变，功能链条整片重写，可维护性、可扩展性受制约 |
| OOP | 按**对象**划分，系统 = 对象集合 | 类 / 对象 | 结构较稳定，子系统相对独立，可重用、可维护、可扩展 |

## 对象

对象是**用来描述客观事物的一个实体**，由一组属性和方法构成。

- 属性：对象具有的各种特征；每个对象的每个属性有特定值。
- 方法：对象执行的操作。
- 素材四例：顾客张浩（姓名/年龄/体重 + 购买商品）、收银员李明（员工号/姓名/部门 + 收款、打印账单、刷卡）、法拉利（品牌/型号/颜色/价格 + 发动、停止、加速）、小狗（颜色 + 叫、跑、吃）。

## 类与对象的关系

- 类：具有相同属性和方法的一组对象的**集合**。
- 类是对象的**抽象**，对象是类的**具体**；类是模板，对象是看得见摸得着的实体。
- 素材例：「人」类有年龄、体重、衣食住行；对象是小布什、普京、克林顿。

## 定义类

Java 程序以类 `class` 为组织单元，`class` 关键字用来定义自定义数据类型。

```java
public class 类名 {
    // 成员变量（属性）
    属性1的类型 属性1;
    // 成员方法
    方法1;
}
```

- 类名首字母大写。
- 三步：定义类名 → 编写属性 → 编写方法。

## 类图

- 用图形分析和设计类，比代码更直观。
- 元素：类名、属性名与类型、方法名与参数、返回值类型。
- 可见性记号：`+` = public，`-` = private。

## 创建与使用对象

```java
类名 对象名 = new 类名();
School center = new School();
center.name = "课工场";
center.showCenter();
```

- 引用属性：`对象名.属性`
- 引用方法：`对象名.方法名()`

## 方法初识

- 方法是一个「黑匣子」：给定输入，完成特定功能并返回结果。
- 定义：`public 返回值类型 方法名() { 方法主体 }`；命名用驼峰。
- 有返回值必须 `return`，且**只能返回一个值**，返回值类型与返回表达式一致；无返回值写 `void`。
- 调用：同类内直接调；跨类先 `new` 出对象再用 `.` 调。
- 素材案例：景区门票按年龄决定票价。

## 素材缺失

- 全篇只讲了「有属性 + 有方法」，**没有 extends、implements、多态，也没有 private 封装/访问修饰符**——面向对象三大特征在本素材里只落地了「封装」的雏形。带参方法、构造方法、`this`、重载在下一篇补：[[2026-10-27-方法与重载]]。
