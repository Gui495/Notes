对 [[raw/Frontend_Backend/Methods_and_Method_Overloading]] 的提炼：带参方法的定义与调用、值传递 vs 引用传递这个最大的坑、构造方法与 `this`、方法重载的判定标准，以及成员变量与局部变量的四组区别。

## 带参数的方法

```java
<访问修饰符> 返回类型 <方法名> <形式参数列表> {
    // 方法主体
}
// 调用
对象名.方法名(参数1, 参数2, ..., 参数n);
```

- 定义处的参数叫**形参**，调用处传入的叫**实参**。
- 常见错误：调用时**不能给实参写类型**（`calc(1, 2)` 而非 `calc(int a, int b)`）；形参与实参的数量、类型、顺序必须一致。

## 方法传参：两个世界

| 传入类型 | 传的是什么 | 方法内改动的影响 |
|---|---|---|
| 基本数据类型 | 变量的**值**（副本） | 改了也不影响调用方 |
| 引用数据类型（类、数组、接口） | 原对象的**引用（内存地址）** | 通过引用改对象内容，会影响原对象 |

```java
public void calc1(int num){ num = num + 1; }          // 外部 n 仍为 8
public void calc2(Student s){ s.age = s.age + 1; }     // 外部 stu.age 变 19
```

判定要点：`calc1` 改的是自己手里的副本；`calc2` 改的是「引用指向的那块对象」——不是把引用本身改掉。

## 构造方法

- 作用：对象初始化。
- 特点：**无返回值类型**（连 `void` 都不写）、方法名与类名相同、可以带参、系统默认提供一个无参构造方法。

```java
访问修饰符 构造方法名() { /* 初始化代码 */ }
```

- 构造方法可以**重载**：同名、参数项不同；与返回值、访问修饰符无关。
- 关键副作用：一旦自定义了构造方法，**系统不再赠送默认无参构造方法**——这是「new 无参报错」的经典原因。

## `this`

- 是对**当前对象**的默认引用。
- 三种用法：调属性 `this.health = 100;`、调方法 `this.print();`、调本类其他构造方法（**必须是构造方法中的第一条语句**）。
- 主要用途：区分同名的成员变量与局部变量。

## 方法重载

- 定义：**同一个类中**方法名相同，**参数个数或类型不同**。
- 与返回值类型、访问修饰符**无关**。
- 素材三例判定：

| 例 | 签名 | 是否重载 | 理由 |
|---|---|---|---|
| A | `method1()` 与 `method1(int i)` | 是 | 参数个数不同 |
| B | `public void method1()` 与 `public int method1()` | 否 | 只有返回值不同 |
| C | `method1()` 与 `int method1(int i)` | 是 | 参数个数不同（返回值不同不影响判定） |

## 成员变量 vs 局部变量

| 维度 | 局部变量 | 成员变量 |
|---|---|---|
| 作用域 | 仅限于定义它的方法 | 整个类内部可见 |
| 初始值 | Java **不**赋初始值，用前必须自己赋值 | Java **会**自动给初始值 |
| 同名约束 | 同一方法内不允许同名 | — |
| 跨方法同名 | 不同方法中可以有同名局部变量 | — |
| 同名优先级 | 成员变量与局部变量同名时，**局部变量优先**（此时用 `this.` 取成员变量） | |

## 素材缺失

- 未讲 `static`、`final` 修饰的方法/变量，也未讲访问修饰符四档（public / protected / 默认 / private）的可见范围。
- 构造方法一节没给「参数化构造 + `this(...)` 链式调用」的完整代码，只给了单参用法提示。
